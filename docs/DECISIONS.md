# Wesentliche Entscheidungen

| Entscheidung | Grund / Herkunft |
|---|---|
| Erwachsene Zielgruppe; Deutsch, Englisch und ägyptisches Arabisch wählbar | Explizite Nutzerfestlegung, am 15. Oktober 2026 um Mehrsprachigkeit erweitert |
| Sieben Alter: 6, 8, 10, 12, 14, 16, 18 | Explizite Klärung der ursprünglich widersprüchlichen Altersangabe |
| Dina bleibt ungefähr 30 | Explizite Nutzerfestlegung; keine automatische Erklärung durch Magie |
| Beide Figuren spielbar | Explizite Nutzerfestlegung; Dina erhält aktive Beiträge |
| Episoden wechseln Fantastik und Realismus | Gewünschte Abwechslung; realistische Episoden erhalten keine magische Auflösung |
| Figuren- und Farbgestaltung v1 beibehalten | Nutzer hat die Entwürfe und sichtbare Spielgestaltung positiv bestätigt |
| Abhängigkeitfreie HTML-/CSS-/JavaScript-Anwendung | Vorhandener funktionierender Prolog; keine Frameworkmigration für die Übergabe nötig |
| Keine laufende KI im Spiel | Offline-Spielbarkeit; Geschichten und Entscheidungen sind lokal definiert |
| Konkrete Entscheidungen statt Gut-/Böse-Punktesystem | Entwurfsentscheidung für nachvollziehbare Folgen und überschaubaren Umfang |
| Lokale Spielstände mit Dateisicherung | Offline-Nutzung; derzeit keine automatische Gerätesynchronisierung |
| Einzeldatei für Laptop plus Web-App für iPhone | Praktischer direkter Offline-Einstieg und geeigneter Safari-Weg |
| GitHub und Sites haben unterschiedliche Rollen | GitHub ist als Entwicklungsablage geplant; bestehende Sites-Identität dient weiter der Veröffentlichung |
| Ein Projektordner und kurze Kontextdateien | Neue Chats sollen gezielt nachlesen können, statt auf den vollständigen alten Chat angewiesen zu sein |
| Natürliches ägyptisches Arabisch für Dialoge und Erzähltexte, arabische Schrift | Explizite Nutzerantwort; vor Freigabe muttersprachliche Prüfung sinnvoll |
| Sprache getrennt vom Spielstand speichern | Wechsel ohne Verlust des Fortschritts; dieselben Rätselkennungen und Entscheidungen in allen Sprachen |
| Version-1-Prologende automatisch zum Fluss migrieren | Bestehende Durchläufe ohne Neustart fortsetzen; Speicherschlüssel und Exportkennung beibehalten |

Neue Einträge sollen eine echte Entscheidung erklären. Routineänderungen gehören in Git und den aktuellen Status.
